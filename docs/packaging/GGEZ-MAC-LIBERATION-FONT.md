Reading the font's SFNT name table identifies Liberation Mono, Version 1.04, and a license field referring generally to the agreement under which the font was obtained; the font itself did not provide a specific license text. The [original Liberation 1.04 source-release notice](https://github.com/liberationfonts/liberation-fonts/blob/ecd28cb9ecd43f227fa8012df506b5b2eaa8945c/tags/liberation-fonts-1.04/License.txt) describes GPLv2 with stated exceptions and other terms. However, the ggez font blob was not found in that inspected source tree and its exact origin or applicable grant has not been proven. Version naming alone does not justify assigning those historical terms to this exact file, nor applying the newer Liberation release's SIL OFL terms retroactively. No determination of GPLv3, GPLv2 or any other precise license for this specific embedded file is made.

For the user's dependency policy, exact source/license provenance and redistribution notice are blockers before treating this ggez binary as a release candidate. A font with verified acceptable terms, such as the separately identified Bevy Fira Mono subset under SIL OFL 1.1, is a possible replacement to evaluate, but changing font metrics, glyph coverage, rendering and captures requires fresh implementation and cross-platform tests. ## Provenance and Fira Mono experiment

Its inspected recursive tree did not contain the ggez font's exact Git blob 8ff67e522402c60bc7a4b22aee797117315f4bb3. The embedded font name is 1.04, but its exact build or upstream grant remains unproven; this is not a finding that GPLv3 applies, nor a legal conclusion.
