# Windows Nannou embedded-font license discrepancy

The exact Noto Sans Regular font found in the [Windows pilot](NANNOU-NOTOSANS-WINDOWS-PILOT-20261113.md) has SHA-256 `f1ce78a25f519ef928b5b8755ca230314e47f8821e7aa89ecf000f033f389a9f`. Reading its OpenType `name` table finds copyright `Copyright 2012 Google Inc. All Rights Reserved.`, license description `Licensed under the Apache License, Version 2.0`, and license URL `http://www.apache.org/licenses/LICENSE-2.0`. Its Noto trademark record also names Google. The matching `notosans@0.1.0` source instead directs readers to its `fonts/LICENSE_OFL.txt`. The font and that notice match the exact pinned upstream blobs documented in the prior report.

An open [Google Fonts issue](https://github.com/google/fonts/issues/3413) discusses the same type of discrepancy between Noto Sans name-table data and distributed OFL notices; it does not decide which terms govern this specific file. We do not choose a license or claim that including both texts resolves obligations. The earlier OFL-only candidate is preserved as historical evidence and should not be treated as release-ready.

A separate unsigned local review candidate retains the original unchanged executable and OFL notice, adds an Apache 2.0 standard-terms copy from the previously audited [gl-rs file](https://github.com/rust-windowing/gl-rs/blob/ea503e8d5fb6d73c6030e6191ce738cd3bf3433e/LICENSE), SHA-256 `cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30`, and records the font copyright and unresolved discrepancy in its README. The 21,812,467-byte ZIP SHA-256 is `aaab7f6ea5e9ea46d76281a9df5ee996a4b029bcfd549fc0de2524f846622141`; the manifest SHA-256 is `bf8974194b57aad96cf217a4c619037d94b21fae94edeec81549a7812022bccb`. All five payload hashes passed after extraction into a separate path containing a space. Executable SHA-256 remains `4b590de541004ee31f7989be554c64a5685ec26c67abbdd1368b8485fbd24624`; no new runtime or input test was performed. Candidate files are in sibling directory `nannou-font-discrepancy-candidate-windows-20261113`; the local name-table inspection script is preserved under `nannou-font-notice-candidate-windows-20261113`.

Both prior and new candidates remain incomplete. Applicable font terms, all other dependency notices and license review, linked and system dependencies, signing, accessibility and clean-machine qualification require review before release. No public release or legal clearance is claimed.
