# Windows Ratatui Rust standard-library distribution trace

This follows the [Windows MSVC link-map audit](RATATUI-WINDOWS-MAP-PROVENANCE.md) of the instrumented Ratatui executable SHA-256 `0bb3eb7b6b2d2f04280155f7caed1224bbef7676810077acf3d0814352be32e7`. The installed Rust toolchain reports `rustc 1.99.1 (58cf8f9c3 2026-10-13)`, host `x86_64-pc-windows-msvc`. Its local channel manifest identifies the official [Windows MSVC rust-std archive](https://static.rust-lang.org/dist/2026-10-15/rust-std-1.99.1-x86_64-pc-windows-msvc.tar.xz) with SHA-256 `4fe09430ded40b8b3092b49f0a651178eb1f8154ef4d1f1a73f2a3595b2d956f`. The 23,619,148-byte download matched that hash.

The five map-named Rust sysroot `.rlib` files (`alloc`, `core`, `panic_unwind`, `rustc_demangle`, and `std`) were read directly from the verified archive and compared byte-for-byte to the installed files; all five matched. The [path-free comparison](ratatui-windows-rust-dist-comparison-20261113.json) SHA-256 is `1efa94fd462bf2277073adaa885477af7955a0bbbb05bf0f2efe5a4f6c7712c4`. This establishes identity with those members of the official distribution, not reproducible provenance from source or a complete list of incorporated code. MSVC `lib /list` also completed for all five, but member names cannot establish all inlined source or license terms.

The installed all-platform `COPYRIGHT-library.html` SHA-256 `5647be074c8edf7339fd863055923a8fc80bc5610a8d4661ec3b767b9d392c27` matches the separately examined [Rust library copyright screen](rust-stdlib-copyright-screen-20261113.json). That broad inventory includes `fortanix-sgx-abi@0.6.1` declared MPL-2.0 and `r-efi`/`r-efi-alloc` entries with LGPL among alternatives. The pinned Rust [`std` manifest](https://github.com/rust-lang/rust/blob/58cf8f9c35b355199727627d07ae34a4e2846d67/library/std/Cargo.toml) gates its direct Fortanix dependency to SGX and its direct r-efi dependencies to UEFI, while declaring a Windows-specific `windows-link` path. Neither `fortanix` nor `r-efi` name appeared in this MSVC link map. These observations limit an inference from the all-platform inventory; they do not prove all possible routes or inlined source are absent from the binary. The other worker's [musl trace](RATATUI-MUSL-DISTRIBUTION-TRACE.md) separately notes a UEFI-gated transitive r-efi route, but that is not a Windows binary attestation.

The official download, raw map-member listings, comparison script and original CRLF comparison remain under task workspace `ratatui-windows-rust-dist-audit-20261113`; the published comparison uses LF. Existing binaries and logs remain unchanged. Exact sysroot source-to-object provenance, all static and dynamic components, Windows runtime license terms, complete notices, clean-machine operation and the owner's strict license condition remain open. No package or release was produced.
