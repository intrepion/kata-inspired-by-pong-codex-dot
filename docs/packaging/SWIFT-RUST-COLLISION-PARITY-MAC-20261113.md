2026-11-13, macOS ARM64, using the corrected Swift Game.swift SHA-256 `4fe688baef4341a6c00138c5f21c725de7baf6327f866c9ac18f249aefae9706` and Rust pong-core lib.rs SHA-256 `68727b4c14adf6e956564db09587f0ff2e5608bf8978bc113433817a3e0902a9`. Both files were verified byte-for-byte against checkpoint `18e83789c37ee016a4d0a7128b48027c6b797c6c`. The checked-in `scripts/swift-rust-collision-parity/run.py` directly compiled the models with Apple Swift 6.4.2 and rustc, then ran 3,060 independently initialized single-step cases against each model. The output directory was newly created and was not a simulator or app data directory.

The grid covers both paddle faces; step sizes 1/120 and 0.033; 17 ball heights including near both walls and paddle edges; vertical velocities -600, -100, 0, 100, 600; player and CPU starting centers 45, 250, 455; and player inputs -1, 0, 1. Horizontal ball speed was 350 toward the tested face. Both models start with seed 42 and the same initialized reaction/target, then receive the same case. The grid includes moving paddles, crossing misses/hits and wall-adjacent paths, but is not exhaustive and does not independently test every CPU-target history, full-game trajectory, UI or physical input.

There were zero bounce-direction mismatches and zero cases with an absolute difference over 0.001 among the six reported ball/paddle coordinates and velocities. Maximum observed absolute differences for x, y, vx, vy, player and CPU were approximately 0.000003, 0.00004, 0.00023, 0.00026, 0 and 0 respectively, comparing the programs' decimal Float output. This is bounded numerical model evidence, not bitwise equivalence or a release qualification.

Reproduce from the repository root with `python3 scripts/swift-rust-collision-parity/run.py /absolute/path/to/new-output-directory`. It requires Python 3, rustc and swiftc and refuses to overwrite an existing output directory. The verified run remains at `/tmp/pong-swift-rust-parity-portable-20261113-v1`, containing the generated cases, outputs and probes; previous data and simulator state were preserved.
