# Windows Nannou no-LUT asset comparison

The [no-LUT probe](NANNOU-NO-LUT-PROBE-WINDOWS-20261113.md) debug executable SHA-256 `30e7cd074dea624ebbacfccdfe8477f38f7ab2ef298e38e34aa6f74dc3be3c48` and the same-adapter [release baseline](NANNOU-READY-WINDOWS-RELEASE-PILOT-20261113.md) SHA-256 `f23e12d687198de4a472ece7108a3546d35a8929916b75cb198ff7df24298359` were searched for complete cached asset byte sequences. The baseline contains the three previously identified Bevy `0.19.1` AgX, Blender Filmic and Tony KTX2 files; the candidate contains none of those exact sequences. Both executables contain the complete cached `notosans@0.1.0` Noto Sans Regular font SHA-256 `f1ce78a25f519ef928b5b8755ca230314e47f8821e7aa89ecf000f033f389a9f` (candidate offset `116412168`, baseline offset `45921048`). Neither contained complete byte sequences of the three other cached Noto variants or Bevy's Fira Mono subset. Negative full-byte searches do not exclude transformed data, different versions or other assets. In particular, LUT removal does **not** resolve the [Noto font license discrepancy](NANNOU-NOTOSANS-LICENSE-DISCREPANCY-WINDOWS-20261113.md).

The candidate's Windows-filtered offline locked feature graph still includes `ruzstd@0.8.3` and shows `nannou_draw` explicitly retaining Bevy's `zstd_rust` feature. No claim is made that removing that feature would remove every path to `ruzstd` or preserve behavior. The path-bearing feature output SHA-256 is `32ae876c24ca611242f451bc3e5fc036dd8ab01855603159dd6eaf6d4b037621`. The path-free complete-byte comparison JSON SHA-256 is `0d7a9a80acf31efb6ac6a0feafd7b3fb6640702b1910ff8aec5cb0a0823b0ee3`. Both and the comparison script remain in sibling worktree `nannou-no-lut-probe-windows-20261113`.

MSVC `dumpbin /dependents` completed successfully for both executables with empty stderr. The baseline listed 25 direct DLL names and the candidate 23: seven names appeared only in the baseline and five only in the candidate. Since one is an optimized release and the other a debug build, this difference cannot be assigned to the LUT change. These are direct import-table names, not actual resolved DLLs or a complete inventory of dynamically loaded, transitive and system dependencies. Raw path-bearing outputs remain in the probe worktree, SHA-256 `1ae66003a80201d680b7764bdb0cd449d5b7d1e1972edddb53d849469587674c` (baseline) and `098c71c3c85290d4ec34295bb95c3fef982e541bfdd6ffc5450388f5db8b0e3c` (candidate).

The eight resolved-graph notice flags, font and other asset terms, the copied dependency's notices, system and runtime library provenance, physical input, clean-machine installation, signing and release qualification remain open. No existing binaries or packages were changed, and this investigation is not license clearance or a public release.
