Run `python3 scripts/verify-ratatui-ctrlc-pty.py /absolute/path/to/pong-ratatui`. These were injected terminal bytes at startup, not physical keyboard or real terminal-emulator testing; it does not test signal delivery, forced termination, or every cleanup path.
