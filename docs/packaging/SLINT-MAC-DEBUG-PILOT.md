# Slint Mac local debug archive pilot

On 2026-11-13, the existing macOS ARM64 debug test app from the [shared pause-input recheck](../GUI-EXPLICIT-PAUSE-INPUT-FIX.md) was copied into a new local tar.gz with the first-party MIT LICENSE and a pilot notice, then extracted to a separate directory. Archive SHA-256: `99936516be1da01c62dc123f3765776de1b119b3f46277aab6ac5260f06e3257`. The extracted executable SHA-256 `92e71de96fb57b7f8ba6044d46fd3c9372d3c35a98e69ec540d6e50bb11bc80b` matched the previously tested binary; its Info.plist passed `plutil -lint`, and the extracted LICENSE matched the original.

Supported desktop automation opened the extracted app, sent Return and observed Playing, sent Space and observed Paused, then sent R and observed 0–0 Playing. The window closed after the exit action. This is sequential automated input on a debug binary; it does not establish physical keyboard input, held-across-pause behavior or a full match. No scripted replay or capture is claimed for this package; an earlier shell replay attempt timed out.

The historical build source was `59957bbdd5f7dd9e61fa1367d522e809b557df62`. Its Slint frontend source, manifest and lockfile, shared GUI model source, and shared core and scenario source have identical Git blobs at checkpoint `3b327f32134e88d44a071386bea61b9ec6b8d6d5`; this is not a new build or a guarantee that every build input and dependency is unchanged. The Slint attribution appeared in the app. This archive includes only the first-party license; third-party notices and license review, signing, notarization, clean-machine operation and distribution remain open. Staging, archive and extraction remain under `/tmp/pong-slint-mac-debug-package-20261113-v1`; earlier artifacts were preserved.
