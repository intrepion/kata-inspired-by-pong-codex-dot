# Nannou Windows Lyon notice recovery

The [prior Windows-filtered Nannou inventory](NANNOU-ACCESSKIT-NOTICES-WINDOWS-20261113.md) contained 19 missing-file flags after AccessKit mappings. Five were Lyon crates, each declaring MIT OR Apache-2.0. Their cached VCS records and exact upstream trees identify two revisions: `lyon@1.0.19` and `lyon_path@1.0.19` at [`56219c9`](https://github.com/nical/lyon/tree/56219c95c658d4f39de7b190d98e57d5773ba241), and `lyon_algorithms@1.0.22`, `lyon_geom@1.0.20` and `lyon_tessellation@1.0.23` at [`db98d26`](https://github.com/nical/lyon/tree/db98d26a1a90076a7a894262dcb51117eef643c8). Cached `src/lib.rs` Git blobs matched the respective upstream files: `979bd80db18bddfd8f2d1727c6e118711df87ae9`, `3dbb5abf8c563b6af9ec9c744260bf4468808939`, `24357fdc284ce716ced675e537b8e4535d2caabd`, `20c50e2ea06aa3f048ab4498fc3168bbfa200045` and `556d1d32b51970f4008daff4daeba82ff1a2d6f5`. Each cached `Cargo.toml.orig` also matched its upstream blob.

The two revisions have identical root `LICENSE-MIT` and `LICENSE-APACHE` Git blobs, `e6d4b179949c58d7a4143d661ccdfecabcebcf54` and `47f4fd0e8982271e9b7662380fae36a1ac007cf1`. The collector now includes those exact texts for the five registry versions only after checking the recorded clean revision, crate path, source hash and notice hashes. The upstream Apache file is a short copyright and license notice referencing the full Apache 2.0 text; it is not the full license. Its inclusion and removal of a missing-file flag do not establish complete Apache notices or legal compliance.

Windows Node collector tests passed 16 cases with one symlink test skipped. Reprocessing the same 424-package Windows-filtered metadata yielded 756 notice entries and 14 remaining missing-file flags. The [path-free index](nannou-windows-notice-index-lyon-20261113.json) SHA-256 is `f0cb08d71e5fa63bfba5c3cbd901256278597e18d1f9246ecfbd9516466aee5c`; the incomplete local bundle SHA-256 is `fa655f77d4e57e9f2983b4fb9482518535be1e4ef768898dafdd92b01f20356f`. The metadata and bundle remain in sibling workspace directories `nannou-notice-refresh-windows-20261113` and `nannou-lyon-notices-windows-20261113`; no package was modified.

The 14 flags, the full Apache text where needed, other source attributions, bundled and system libraries, actual linked code, license choices, legal review, clean-machine installation and release qualification remain open. This is not license clearance; no public release was made.
