# Windows Nannou pilot Noto Sans notice

**Follow-up:** The font's own name table identifies Apache 2.0, while the crate points to an OFL notice. The [discrepancy investigation](NANNOU-NOTOSANS-LICENSE-DISCREPANCY-WINDOWS-20261113.md) supersedes any inference that the OFL notice alone is sufficient. Applicable terms remain unresolved.

The preserved [Windows release pilot](NANNOU-HELD-WINDOWS-RELEASE-PILOT.md) executable SHA-256 `4b590de541004ee31f7989be554c64a5685ec26c67abbdd1368b8485fbd24624` contains the complete 203,084-byte `notosans@0.1.0` `NotoSans-Regular.ttf` sequence at offset 45,893,560. The cached font SHA-256 is `f1ce78a25f519ef928b5b8755ca230314e47f8821e7aa89ecf000f033f389a9f`. Full-byte searches did not find that crate's Bold, Italic or BoldItalic fonts, or the cached `bevy_text@0.19.1` Fira Mono subset; these negative results do not rule out transformed or other assets.

The notosans source includes the regular font with `include_bytes!` and refers to `fonts/LICENSE_OFL.txt`. Its cached VCS revision is [5f93075](https://github.com/nannou-org/notosans/tree/5f93075c61617b3b4cc970da2f763eba84873d26). Cached regular font, source, original manifest and font notice match upstream blobs `b5377abcaa12237a36ec80ad0b1ad22509f5338b`, `f65555a91710eb7430eeedd8067bfc60a8ebe877`, `9a31ba32b530c06937fe0a7b207b42dec38a4565` and `d952d62c065f3f35fb83a173496e90b21525aef3` respectively. The [notice](https://github.com/nannou-org/notosans/blob/5f93075c61617b3b4cc970da2f763eba84873d26/fonts/LICENSE_OFL.txt) SHA-256 is `6a73f9541c2de74158c0e7cf6b0a58ef774f5a780bf191f2d7ec9cc53efe2bf2`. The crate's MIT OR Apache-2.0 metadata does not by itself describe the bundled font terms.

The original pilot staging directory contains the executable, project license, pilot README and hash manifest, but no separate font notice. A separate unsigned local candidate adds the exact cached notice as `NotoSans-LICENSE-OFL.txt`, updates its incomplete-pilot README and regenerates its manifest. The 21,808,199-byte ZIP SHA-256 is `4f73c9b5c068464683029dc7e7edb2c263b0e21d2c5d8a34c65e3791a6cb837e`; its manifest SHA-256 is `e222046dc4459e3ab94723c00cd980e63c63c618758140f1cb395f5913ed750e`. All four payload hashes passed against the manifest after extraction to a separate path containing a space. The executable hash remains unchanged, so the earlier scripted replay and capture evidence applies to these bytes; no new runtime or physical-input check was performed. The candidate, staging and extracted files remain in sibling directory `nannou-font-notice-candidate-windows-20261113`; original packages and artifacts are preserved.
