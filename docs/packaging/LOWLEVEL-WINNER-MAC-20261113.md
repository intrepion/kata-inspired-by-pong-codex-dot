# Shared low-level winner indication

2026-11-13. SDL3, ash and softbuffer use the shared low-level rectangle model. Previously its non-playing overlay displayed pause bars even when a match was over, and the title did not name the winner. It now draws a compact built-in rectangle glyph label `YOU WIN` or `CPU WINS`, highlights the winning score and puts the winner in the existing window title. Ready and Paused retain the prior bars; a tied Over state has a neutral title and no winner marker. No font or new dependency was added.

On macOS ARM64, the offline locked release-profile shared suite passed 4/4. Its new test scores the winning point for each side, checks the title and rasterized winning-score marker, verifies pause-bar geometry is absent, and checks restart clears the marker. The dependent SDL3 (9), ash (11) and softbuffer (9) test suites also passed against the final shared code, using existing cached targets. Tested shared lib.rs SHA-256 `0da04e454812f7a11e628eaae6c48fea36221264201e03c49a52c8f10e9f5f90`; source was based on checkpoint `b18d45f2ba88c1668a68cfcbc6e89cbd6a0939c4` and the shared file was checked unchanged against `0800a0b2b0502d2ee0695a66c70024ed8574ab6c` before publication.

Two isolated 900×500 software-raster fixtures advanced the model to each winning score and were visually inspected: player `YOU WIN` and CPU `CPU WINS` were legible with the correct highlighted score. Their PNG SHA-256 values are respectively `622ada542daa076e11f21d3175024e353ceb5566ec8bfdccc619778dc65ec539` and `2a79d76c03dd085e7a45635490c39ae874213db8be8f4f883a07b7fdea5a8ac6`, under `/tmp/pong-lowlevel-winner-preview-20261113-v1`. Existing data and artifacts were retained.
