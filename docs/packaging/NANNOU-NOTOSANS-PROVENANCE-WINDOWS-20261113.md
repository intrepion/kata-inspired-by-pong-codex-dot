# Windows Nannou Noto Sans upstream provenance

The font embedded in the historical pilot has SHA-256 `f1ce78a25f519ef928b5b8755ca230314e47f8821e7aa89ecf000f033f389a9f` and Git blob `b5377abcaa12237a36ec80ad0b1ad22509f5338b`, matching the pinned `notosans@0.1.0` crate. Its name table identifies Noto Sans Regular, version `1.04 uh`, copyright 2012 Google, and Apache 2.0. The byte-identical 203,084-byte blob exists in the Noto project's [2014 revision 0837e75](https://github.com/notofonts/noto-fonts/tree/0837e75e182418c2fd74ad2519d402fd0f04c5c6/individual/unhinted) at `individual/unhinted/NotoSans-Regular.ttf`. Matching the blob establishes identical bytes at that revision; it does not establish the intermediate path by which the crate obtained them.

The recursive tree for that 2014 revision has `LICENSE` and `COPYING` entries in the hinted and unhinted directories, but each is a Git symlink with blob `5853aaea53bc07801e8ee3af2e700849e30fb6a0`, containing `../../../LICENSE`; that target lies outside the repository tree. No actual license text was found in that tree. The font's own Apache name-table entry is separate evidence; the dangling links do not establish an accompanying license text.

Google Fonts [moved Noto Sans from `apache` to `ofl` in 2016](https://github.com/google/fonts/commit/23ae8ad0a299ea63929355b5e4e38a4fbf999f8a). The moved Regular font retained Git blob `a5a25a4a834910853cbf19883c430615ef6b8e82`, which differs from the pilot font. The added `OFL.txt` blob `d952d62c065f3f35fb83a173496e90b21525aef3` is byte-identical to the notice later included in the 2019 Nannou font crate. This proves the notice's presence in that 2016 Google Fonts tree, not that the different 2014 font blob was included in the move or that later distribution settled its terms. The Noto project also has a [2015 font update described as using OFL](https://github.com/notofonts/noto-fonts/commit/ad153f5a14c838afb16c83f0a02784c7605f1e21); its unhinted Regular blob `ebd7703f6906b4810dac8112f9188adfb0427495` differs from the pilot's blob.

The two candidate packages and their hashes described in the [discrepancy report](NANNOU-NOTOSANS-LICENSE-DISCREPANCY-WINDOWS-20261113.md) remain unchanged. The exact font's applicable license terms and notice sufficiency require review; neither the later move nor the presence of both texts is legal clearance. Other dependency notices, linked and system dependencies, signing, accessibility and clean-machine checks remain open. No public release was made.
