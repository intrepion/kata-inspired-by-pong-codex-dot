# Windows Cargo copyleft discovery pass

On 2026-11-13, offline locked `cargo metadata --filter-platform x86_64-pc-windows-msvc` was examined for first-party experiment manifests with cached dependencies. Of 25 attempted manifests, 23 resolved successfully; `godot` and `gui-gtk` could not resolve because the local offline cache lacked their respective `godot` and `gtk4` packages. Resolved node license expressions were searched case-insensitively for `GPL`. This is a metadata discovery pass, not a complete source, transitive native library, feature or binary license audit. The raw metadata and errors, which contain local paths, remain under task workspace `windows-lgpl-metadata-audit-20261113` and are not published.

No resolved node in those 23 graphs declared LGPL in its Cargo license expression. However, the existing Windows SDL3 notice index identifies `SDL_mixer/external/flac/COPYING.LGPL` inside `sdl3-mixer-src@3.2.4`, whose crate-level declaration is Zlib. The same source tree includes other license files. This flags bundled source for review, not a determination that FLAC or LGPL-covered code is built, linked or distributed. For the current default Windows SDL3 configuration, `cargo tree --locked --offline --target x86_64-pc-windows-msvc -e normal,build -i sdl3-mixer-src` printed no dependency path; the feature-tree query also printed none. Cargo metadata includes optional resolved packages, so those observations must not be conflated.

The Slint graph contained 11 resolved package records with `GPL-3.0-only OR LicenseRef-Slint-Royalty-free-2.0 OR LicenseRef-Slint-Software-3.0`: `slint`, `slint-macros`, `i-slint-backend-selector`, `i-slint-backend-testing`, `i-slint-backend-winit`, `i-slint-common`, `i-slint-compiler`, `i-slint-core`, `i-slint-core-macros`, `i-slint-renderer-skia`, and `i-slint-renderer-software`, all version `1.18.1`. The normal/build dependency tree identifies `slint` as a direct dependency of `pong-slint`; the corresponding inverse queries for backend-testing and renderer-skia printed no path for this configuration. These expressions offer alternatives; this scan does not determine eligibility, selected terms, linking, or redistribution obligations. Review the actual selected features, license texts and applicable terms before distribution.

Absence of a GPL/LGPL string from Cargo declarations does not establish absence in bundled C/C++ source, system libraries, dynamically loaded components or assets. Godot and GTK remain unscanned in this pass, and the SDL_mixer notice result is based on available local notice indexes rather than an exhaustive search of all source. Preserve prior notice bundles and packages; none were altered. No legal clearance, clean-machine qualification or public release is claimed.
