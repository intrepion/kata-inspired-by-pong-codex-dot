# bracket-lib Windows notice-source investigation

The [Windows bracket-lib release pilot](BRACKET-HELD-WINDOWS-RELEASE-PILOT.md) retained seven missing-notice flags. This bounded pass examined the three `bracket-*` packages in the existing Windows-filtered offline locked graph, without changing the package or substituting notice text. `bracket-embedding`, `bracket-noise` and `bracket-rex` are each version `0.8.7`, declare MIT in Cargo metadata, and their published registry records identify bracket-lib revision `15ec23aba4ec0c147f9ec54d2429a59c1bb6319c` with their respective crate directory as `path_in_vcs`. A [root MIT license](https://github.com/thebracket/bracket-lib/blob/15ec23aba4ec0c147f9ec54d2429a59c1bb6319c/LICENSE) exists at that upstream revision, but the registry crate directories inspected contain no conventional license file. The root license's existence alone does not establish that it covers every included source or resolves attribution.

The local `bracket-noise/src/fastnoise.rs` identifies itself as a port of FastNoise and describes the original as MIT; the [upstream source at the recorded revision](https://github.com/thebracket/bracket-lib/blob/15ec23aba4ec0c147f9ec54d2429a59c1bb6319c/bracket-noise/src/fastnoise.rs) contains the same attribution. The local file SHA-256 is `8b421a46dee1625f7b5af78fe29ff37819bf49551bac3eb1db22372269a2c811`. The local `bracket-rex/src/rex.rs` attributes derivation to rs-rexpaint and identifies that work as DWTFYW Public License 2.0; its [upstream counterpart](https://github.com/thebracket/bracket-lib/blob/15ec23aba4ec0c147f9ec54d2429a59c1bb6319c/bracket-rex/src/rex.rs) contains the attribution. The local file SHA-256 is `b526bff394601d6971b273c7116eaf180511b38f7fc5156a45bd7fd0c4db5545`. These are source statements, not independent verification of the upstream origin, exact originating revision, license terms or their adequacy for distribution. Matching visible statements were checked; a byte-for-byte comparison against the remote files was not performed.

For the current default Windows target, `cargo tree --locked --offline --target x86_64-pc-windows-msvc -e normal,build -i` shows all three crates in the enabled dependency graph: `bracket-noise` via `bracket-lib`, `bracket-rex` via `bracket-terminal`, and `bracket-embedding` via terminal and rex. This does not prove individual functions survive linking or determine obligations. The remaining original flags are `gl_generator`, `khronos_api`, `ultraviolet` and `windows_x86_64_msvc`; they were not resolved here. All seven flags remain open pending precise original-source and notice review, including the full license texts where applicable, linked-code and bundled-source assessment, and system dependencies. Existing metadata, notice bundles, pilot artifacts and source caches were preserved; no licensing or release clearance is claimed.
