# Yew internal focus and Pause button

On Omarchy, Chrome loaded the existing Yew WASM build from a localhost server. After Start and clicking the court to focus the game root, the first Pause / Resume click left play running; a second click displayed Paused. This is supported automated browser interaction, not physical input. The served WASM SHA-256 was `ba9c4f260c7ff0bcf33666ba2941729a01f89ed0e817062cb0e0eb20071b5423`, the earlier `2608321cba71789fe03cdff5cf1d7979277840a6` debug build documented in [the package pilot](packaging/YEW-PAUSE-OMARCHY-PILOT.md). Its Yew event-handler and shared-controller source match pre-fix checkpoint `cc1c6099ae61538f20537fd41b0480e5c5c998b2`. The localhost server and test tab were closed after the check; prior artifacts were retained.

The observed sequence is consistent with root blur pausing the session as focus moves to its own Pause button, followed by the button click toggling back to Playing. The Yew handler now checks whether the focus event's related target is inside the game root; internal transitions do not pause, while focus leaving the root still pauses and clears input. A focused shared-controller regression failed before the change and passed afterward: internal focus followed by Pause remains Paused, and external focus loss pauses and clears held movement. All 13 shared-controller tests and a locked offline Yew WASM `cargo check` pass. The check used a separate copy of the prior build cache at `/tmp/pong-yew-focus-target-20261113`; no new browser binary was generated.

This is a pre-fix browser reproduction plus model and compilation evidence for the change, not a post-fix browser or native-wrapper pass. Matching `wasm-bindgen` CLI was not available on PATH or in the searched local tool locations, so the updated WASM was not packaged or browser-tested here. Leptos and Dioxus have similar root blur handlers but were not changed or browser-reproduced in this check. Keyboard activation on focused Yew controls, real focus loss, physical input, other platforms and release qualification remain open. Cross-machine requalification should use localhost for browser tests.
