# Leptos and Dioxus internal-focus investigation

On Omarchy, Chrome loaded the existing Leptos build from a localhost server. After Start and clicking the court to focus the game root, the first Pause / Resume click left the game playing; the second showed Paused. This is automated browser interaction, not physical input. The served WASM SHA-256 was `4cf8b5974edbb45608568e1705762301d705745a12cfc832a486aebabcce0525`, the earlier debug build from `0cf9e95f3a95f3618834040dec7bd68c95e8f869` documented in [the package pilot](packaging/LEPTOS-PAUSE-OMARCHY-PILOT.md). The Leptos handler is unchanged between that revision and pre-fix checkpoint `f4c9c6138a06dedc059271c8f9ad1dd094ef8e54`. The test tab and localhost server were closed afterward; prior artifacts were retained.

Leptos now listens for bubbling focus-out and checks whether the related target is still within the game root. Internal focus transitions no longer invoke pause; focus leaving the root invokes the [shared focus policy](YEW-INTERNAL-FOCUS-PAUSE-FIX.md), which pauses and clears held input. That policy's regression failed before the Yew fix and passes, along with all 13 shared-controller tests. Leptos passed a locked offline WASM check and a separate raw debug WASM build; source Git blob `fae6826c5a4331ceb0d3423167aed036a1da17b1`, raw WASM SHA-256 `f1985cfa24b355d93be671c0b845b208d23ed0d66448a01a00e52d758066ff66`, retained under `/tmp/pong-leptos-focus-target-20261113`. This raw module is not the browser-ready bindgen output. The matching `wasm-bindgen` CLI was not found locally, so no post-fix browser or wrapper interaction is claimed.

Dioxus retains a similar root `onblur` handler, but the available local Dioxus build is a native desktop wrapper and no Dioxus browser build or supported native desktop surface was available for this check. Its actual focus/click sequence remains unconfirmed and no Dioxus behavior was changed. The pinned Dioxus focus-event data exposes no related target, and the desktop event converter receives an empty serialized focus payload, so the Leptos/Yew target-containment approach cannot simply be copied into that desktop adapter. A platform-appropriate focus test and design are needed before changing it. Physical input, post-fix browser behavior, native wrappers, cross-platform and release qualification remain open; browser tests must use localhost.
