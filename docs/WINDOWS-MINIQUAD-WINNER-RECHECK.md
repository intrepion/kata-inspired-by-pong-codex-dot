## Reachable game-over ball position

The centered-ball overlap in the forced-state images above is an artifact of initializing `Game::new` and directly setting `State::Over`. In the shared core, a winning point changes Playing to Over only after the ball center crosses `x < -BALL` or `x > W + BALL`; unlike a non-winning score, the winning path does not reset the ball. Since Miniquad draws the ball with radius `BALL`, it is beyond the court edge at that transition and cannot overlap the centered winner text in a normally reached game-over state. This conclusion assumes the normal core transition rather than externally mutating public game fields.
