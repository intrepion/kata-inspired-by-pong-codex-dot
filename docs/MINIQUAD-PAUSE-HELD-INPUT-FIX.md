# Miniquad explicit-pause held-input fix

Miniquad's minimize path already cleared held movement, but explicit Space pause previously left movement bindings active. A new adapter-boundary test reproduced the stale axis after pause. If a key remained held, repeated key-down events could also restore a cleared binding. The shared physics was not changed.

The Miniquad key-down adapter now clears movement when Space transitions Playing to Paused, and ignores repeated movement key-down events; a fresh press after resume moves normally. The regression covers W, Up, S and Down individually, and failed before the fix. All nine Miniquad adapter tests and an offline locked release build passed on Omarchy ARM64.
