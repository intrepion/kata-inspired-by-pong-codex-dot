# Pong atlas sources
Both PNGs are generated from the original glyph drawings in
`generate-atlases.py` for this Pong adapter, under the repository MIT license.
No pixels, font files, or glyph tables from either original bracket-lib atlas
or from an external source are used. The generator takes no font input.
The blank and divider slots serve the court; the HUD atlas serves the
game's ASCII text. Other CP437 cells are not provided by these game assets.

Regenerate with `python3 experiments/bracket-lib/assets/generate-atlases.py`;
pass `--check` to verify the two independently generated bytes and the Rust
source glyph coverage without writing. PNGs are 16×16 cells, RGBA, with
transparent background and white foreground. Each HUD source row is doubled.

- `pong-court8x8.png`: SHA-256 `42c882def2707f1f1484dac5714414d86e8e28dc572a09c2613bf448541e9b4d`
- `pong-header8x16.png`: SHA-256 `a9340533514534303b41de665ed64bd57383465c4bff014feb3371071e3596cd`

This replacement does not cover archive inputs outside this adapter. Do not
include upstream `bracket-terminal` resource directories or registry/source
caches in the executable distribution.
